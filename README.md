# Safa Two

Проект представляет собой адаптивный лендинг с анимациями, созданный по макету. Подходит для использования в качестве шаблона для презентации продукта.

## 🚀 Начало работы

Инструкции по установке и запуску проекта на локальной машине.

### Установка

1. Клонируйте репозиторий с рабочей ветки dev:

git clone https://github.com/ArinaTer/safa-two.git


2. Установите зависимости:

npm install


3. Запустите проект:

npm run dev
